# Library Desk — Infobutton & Mehrfachauswahl

**Datum:** 2026-10-16  
**Status:** Umsetzung

## Infobutton (ⓘ)

Links über der Liste neben Neu/Auswählen. Zeigt:

- Anzahl Version-Gruppen: Gesamt / Suno / Allgemein
- Letzte Sicherung/Export: Zeitpunkt + Dateiname  
  Erfasst bei jedem erfolgreichen Export (Bibliothek, Eintrag, Auswahl, Auto-Backup) via Setting `lastLibraryExport`.

## Auswahlmodus

- **Alle** — alle sichtbaren Gruppen
- **Shift+Klick** — Bereich vom Anker bis zur Zeile
- Einfacher Klick/Checkbox — einzelne Umschaltung (setzt Anker)
